# Social Media Harness

This harness provides agent-native access to social media trend intelligence,
account optimization, and theme page strategy tools.

See [agent-harness/SOCIAL_MEDIA.md](agent-harness/SOCIAL_MEDIA.md) for full documentation.

## Quick commands for Claude Code agents

```bash
# Get trending hashtags and music (demo mode)
social-media trends

# Analyze a niche before creating theme page
social-media niche motivation

# Generate 7-day content calendar
social-media calendar fitness

# Get full monetization funnel
social-media funnel finance

# Optimize your account
social-media account --username mypage --followers 5000 --niche motivation --platform tiktok --posts 20 --avg-views 1200 --avg-likes 80 --avg-comments 5 --avg-shares 8
```
