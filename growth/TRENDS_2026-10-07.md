# Trend scan & theme-page playbook — 2026-10-07

Research from public web search only. No account handles, credentials or
platform API keys exist in this repo or session, so nothing has been
published or changed on any account.

## Trends (TikTok)
- Formats: "Suspect" (slow-motion jog, "suspect is…" caption), "Subtle Foreshadowing" (early detail pays off in a twist).
- Sound: "Two Fishes" (Corbin Mims, Love Island USA S8) — used to win arguments with parents.
- Seasonal: Halloween falls on a Saturday, so costume/cliffhanger content peaks over the weekend. Post the week of Oct 19–30.

## Trends (YouTube Shorts)
- Halloween reveals, challenges, visual comedy, music-fandom moments, useful micro-content, mini vlogs.
- YouTube surfaces trending-song cards with a one-tap "create Short"; early adoption of sounds reportedly lifts reach ~21%.

## Theme-page playbook
1. One niche, one promise; consistent visual identity.
2. Don't just repost: find winning hooks in the niche, recreate with original footage.
3. Cross-post (TikTok / Reels / Shorts), native upload, no watermarks.
4. Monetise: affiliate links, own digital products, sponsored posts, shoutouts.
5. Build an email list / link-in-bio funnel — owned audience.
6. Engage: reply to comments, collaborate in niche.

## To implement on accounts (needs from owner)
- List of account handles + niches.
- Platform API access (TikTok Content Posting API, YouTube Data API key/OAuth) or a scheduler login.
- Then: 3 posts/day/account using the formats above, hashtag set = niche tag + 1–2 trend tags, bio link to funnel.
