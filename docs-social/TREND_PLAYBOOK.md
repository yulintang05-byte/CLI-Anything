# Social Trend Playbook (TikTok + YouTube Shorts) — 2026-10-17

Status: research snapshot. Nothing here has been posted to any account; this repo
holds no account handles or credentials (see "Blockers").

## Trends found (third-party trackers; verify live before posting)
- **TikTok sounds (Oct):** Love Island USA sound for mock-serious debates; Roisin Murphy
  "Ramalama (Bang Bang)" for Halloween costume reveals (New Engen weekly tracker, updated Oct 14).
- **TikTok hashtags:** seasonal — #halloween2026 #spookyseason #fall2026 #pumpkinspice; evergreen #fyp #viral.
  Live ranking: TikTok Creative Center > Trend Discovery (filter region + industry).
- **YouTube Shorts:** Halloween reveals, challenge videos, visual comedy, non-verbal demos,
  music-fandom edits, serialized Part 1/2/3, useful micro-content. Early-adopted sounds reportedly
  lift reach; original audio does better for educational content. Unscripted > polished.
- Caveat: figures (e.g. "+21% reach", "61% of views from Shorts feed") are unverified marketing claims.

## Theme-page conversion model
1. One niche for the first ~30 posts; validate with TikTok search volume, existing earners, adjacent ad demand.
2. Monetization stack: Creator Rewards (original videos >1 min), TikTok Shop/affiliate, brand deals, own product/funnel.
3. Set up the bio-link funnel *before* followers: one link -> lead magnet/offer -> email/SMS capture.
4. Add a real transformation layer to every post (commentary, editing, original angle). Raw TTS over
   reused footage gets throttled/demonetized.
5. Track per-post: 3s hold, completion, shares, profile visits, link clicks, conversions.

## Per-account weekly loop
- Mon: pull Creative Center hashtags/sounds + YouTube trending Shorts; shortlist 5.
- Tue-Sun: post 1-3/day using shortlisted sound/format; 3-5 hashtags (1 trend, 2 niche, 1 broad).
- Sun: keep top 20% by hold/share rate, retire the rest.
