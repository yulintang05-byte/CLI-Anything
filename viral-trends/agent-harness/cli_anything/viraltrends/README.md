# ViralTrends

Agent-native CLI for YouTube + TikTok viral trend intelligence.

**Commands:** `trends`, `hashtags`, `music`, `niche`, `account`, `themepage`

See [VIRALTRENDS.md](../../../VIRALTRENDS.md) for full documentation.

## Quick Start

```bash
pip install -e .
viraltrends trends tiktok
viraltrends hashtags both
viraltrends account optimize tiktok --niche-name fitness
viraltrends themepage playbook finance --platform tiktok
```
